# Serious Sam Tournaments Ranking

Рейтинг игроков **Serious Sam HD: The Second Encounter** и **Serious Sam 3: BFE**, основанный на результатах матчей.

**[Перейти на сайт →](https://denwhai.github.io/serious-sam-tournaments-ranking/)**

Для просмотра достаточно открыть сайт — установка и регистрация не требуются.

## Что доступно на сайте

- Переключение между TSE и BFE.
- Текущий рейтинг и предыдущие выпуски с указанием периода оценки.
- **Simple** — места, Points, результаты матчей и характеристика игрока.
- **Advanced** — подробные показатели эффективности и статистика карт и режимов.
- Сортировка по показателям, поиск игрока и сравнение изменений Points и места.
- Объяснение формулы и каждого параметра рейтинга.
- Русский и английский языки.
- Скачивание таблиц в CSV и данных выпуска в JSON.

## Выпуски рейтинга

Рейтинг обновляется ежемесячно. Для будущих выпусков предусмотрено окно оценки матчей за четыре месяца со сдвигом на один месяц вперёд.
